## 项目概述

### 什么是 DKail？

DKail 是一个轻量级的本地网络安全监控系统，通过原生代码实现核心安全监控功能，无需依赖复杂的外部平台。它专注于提供实时、高效的网络安全监控能力，帮助用户及时发现和响应安全威胁。

### 核心特性

- **实时网络流量监控**：捕获和分析网络数据包，识别可疑连接
- **进程行为监控**：监控系统进程活动，检测可疑进程
- **威胁检测**：基于特征匹配的威胁检测系统
- **Web管理界面**：提供直观的管理界面，实时查看监控数据
- **桌面应用**：独立的桌面应用程序，类似Kali Linux工具风格

### 设计理念

1. **轻量级**：使用原生代码实现，避免重量级依赖
2. **高性能**：异步架构，充分利用多核处理器
3. **易扩展**：模块化设计，便于添加新功能
4. **安全第一**：遵循安全最佳实践，最小权限原则

## 核心模块详解

### 1. 网络监控模块 (Network Monitor)

#### 功能概述

网络监控模块负责实时捕获和分析网络流量，识别可疑连接和异常行为。

#### 实现原理

##### 1.1 数据包捕获

使用 `pcap` 库捕获网络数据包：

```rust
use pcap::Device;

pub struct NetworkMonitor {
    interface_name: String,        // 网络接口名称
    packet_count: u64,             // 数据包计数
    byte_count: u64,               // 字节计数
    connection_stats: HashMap<String, ConnectionStats>, // 连接统计
}

impl NetworkMonitor {
    pub fn new(interface_name: String) -> Self {
        Self {
            interface_name,
            packet_count: 0,
            byte_count: 0,
            connection_stats: HashMap::new(),
        }
    }
    
    pub async fn start_capture(&mut self, state: Arc<RwLock<SystemState>>) -> Result<(), Box<dyn std::error::Error>> {
        // 打开网络接口
        let device = Device::list()?
            .into_iter()
            .find(|d| d.name == self.interface_name)
            .ok_or("Interface not found")?;
        
        let mut cap = Capture::from_device(device)?
            .promisc(true)          // 混杂模式
            .snaplen(65535)         // 捕获完整数据包
            .open()?;
        
        // 循环捕获数据包
        loop {
            match cap.next_packet() {
                Ok(packet) => {
                    self.process_packet(packet.data);
                }
                Err(e) => {
                    warn!("Packet capture error: {}", e);
                }
            }
        }
    }
}
```

**技术要点**：
- **混杂模式 (Promiscuous Mode)**：允许捕获所有经过网卡的数据包，而不仅仅是发往本机的数据包
- **快照长度 (Snaplen)**：设置捕获的数据包最大长度，65535表示捕获完整数据包
- **异步处理**：使用异步I/O避免阻塞主线程

##### 1.2 数据包解析

解析以太网帧、IP头部、TCP/UDP头部：

```rust
fn process_packet(&mut self, data: &[u8]) {
    // 解析以太网帧
    if data.len() < 14 {
        return;
    }
    
    let ethertype = u16::from_be_bytes([data[12], data[13]]);
    
    match ethertype {
        0x0800 => self.analyze_ipv4_packet(data),  // IPv4
        0x86DD => self.analyze_ipv6_packet(data),  // IPv6
        _ => {}
    }
}

fn analyze_ipv4_packet(&mut self, data: &[u8]) -> Result<(), Box<dyn std::error::Error>> {
    // 安全检查：验证数据包长度
    if data.len() < 20 {
        return Ok(());
    }
    
    // 解析IP头部
    let version = data[0] >> 4;
    let ihl = (data[0] & 0x0F) as usize * 4;  // IP头部长度
    
    // 边界检查：确保IHL字段有效
    if version != 4 || ihl < 20 || data.len() < ihl {
        return Ok(());
    }
    
    let protocol = data[9];
    let source_ip = format!("{}.{}.{}.{}", data[12], data[13], data[14], data[15]);
    let dest_ip = format!("{}.{}.{}.{}", data[16], data[17], data[18], data[19]);
    
    // 解析传输层协议
    match protocol {
        6 => self.analyze_tcp_packet(&data[ihl..], &source_ip, &dest_ip)?,
        17 => self.analyze_udp_packet(&data[ihl..], &source_ip, &dest_ip)?,
        _ => {}
    }
    
    Ok(())
}

fn analyze_tcp_packet(&mut self, data: &[u8], source_ip: &str, dest_ip: &str) -> Result<(), Box<dyn std::error::Error>> {
    // 边界检查：TCP头部最小20字节
    if data.len() < 20 {
        return Ok(());
    }
    
    let source_port = u16::from_be_bytes([data[0], data[1]]);
    let dest_port = u16::from_be_bytes([data[2], data[3]]);
    let seq = u32::from_be_bytes([data[4], data[5], data[6], data[7]]);
    let ack = u32::from_be_bytes([data[8], data[9], data[10], data[11]]);
    let flags = data[13];
    
    // 更新连接统计
    let key = format!("{}:{}->{}:{}", source_ip, source_port, dest_ip, dest_port);
    let stats = self.connection_stats.entry(key).or_insert(ConnectionStats {
        source_ip: source_ip.to_string(),
        dest_ip: dest_ip.to_string(),
        source_port,
        dest_port,
        protocol: "TCP".to_string(),
        packet_count: 0,
        byte_count: 0,
        first_seen: Instant::now(),
        last_seen: Instant::now(),
    });
    
    stats.packet_count += 1;
    stats.byte_count += data.len() as u64;
    stats.last_seen = Instant::now();
    
    Ok(())
}
```

**安全知识**：
- **以太网帧结构**：目标MAC(6字节) + 源MAC(6字节) + EtherType(2字节) + Payload(46-1500字节)
- **IPv4头部结构**：版本(4bit) + IHL(4bit) + 服务类型(8bit) + 总长度(16bit) + ...
- **TCP头部结构**：源端口(16bit) + 目标端口(16bit) + 序列号(32bit) + 确认号(32bit) + ...
- **边界检查**：防止缓冲区溢出攻击，确保数据包长度有效

##### 1.3 连接统计与清理

```rust
#[derive(Debug, Clone)]
pub struct ConnectionStats {
    pub source_ip: String,
    pub dest_ip: String,
    pub source_port: u16,
    pub dest_port: u16,
    pub protocol: String,
    pub packet_count: u64,
    pub byte_count: u64,
    pub first_seen: Instant,
    pub last_seen: Instant,
}

impl NetworkMonitor {
    // 定期清理过期连接，防止内存泄漏
    pub fn cleanup_stale_connections(&mut self, max_age: Duration) {
        let now = Instant::now();
        self.connection_stats.retain(|_, stats| {
            now.duration_since(stats.last_seen) < max_age
        });
    }
}
```

**内存管理**：
- **HashMap清理**：定期清理超过5分钟未活动的连接
- **最大连接数限制**：限制最大10000个连接，防止内存耗尽
- **RAII模式**：确保资源正确释放

##### 常见网络攻击检测

### 2. 进程监控模块 (Process Monitor)

#### 功能概述

进程监控模块负责监控系统进程活动，检测可疑进程和异常行为。

#### 实现原理

##### 2.1 进程枚举

使用Windows API枚举系统进程：

```rust
use winapi::um::psapi::EnumProcesses;
use winapi::um::processthreadsapi::OpenProcess;
use winapi::um::winnt::PROCESS_QUERY_LIMITED_INFORMATION;
use winapi::um::handleapi::CloseHandle;

pub struct ProcessMonitor {
    process_cache: HashMap<u32, ProcessInfo>,
}

#[derive(Debug, Clone)]
pub struct ProcessInfo {
    pub pid: u32,
    pub name: String,
    pub path: String,
    pub parent_pid: u32,
    pub create_time: u64,
    pub is_suspicious: bool,
}

impl ProcessMonitor {
    fn enumerate_processes(&mut self) -> Result<(), Box<dyn std::error::Error>> {
        use std::mem::size_of;
        
        let mut process_ids: [u32; 1024] = [0; 1024];
        let mut bytes_returned: u32 = 0;
        
        // 调用Windows API枚举进程
        unsafe {
            if EnumProcesses(
                process_ids.as_mut_ptr(),
                (1024 * size_of::<u32>()) as u32,
                &mut bytes_returned
            ) == 0 {
                return Err("EnumProcesses failed".into());
            }
        }
        
        // 安全检查：限制进程数量上限
        let process_count = (bytes_returned as usize / size_of::<u32>()).min(1024);
        
        // 遍历进程列表
        for i in 0..process_count {
            let pid = process_ids[i];
            if pid == 0 {
                continue;
            }
            
            if let Ok(info) = self.get_process_info(pid) {
                self.process_cache.insert(pid, info);
            }
        }
        
        Ok(())
    }
}
```

**技术要点**：
- **EnumProcesses API**：Windows API，用于枚举系统中的所有进程
- **边界检查**：限制进程数量上限为1024，防止缓冲区溢出
- **错误处理**：跳过无法访问的进程（如系统进程）

##### 2.2 进程信息获取

使用RAII模式管理进程句柄：

```rust
use std::ops::Deref;

// RAII包装器，确保句柄正确关闭
pub struct ProcessHandle {
    handle: *mut winapi::ctypes::c_void,
}

impl ProcessHandle {
    pub unsafe fn new(handle: *mut winapi::ctypes::c_void) -> Self {
        Self { handle }
    }
    
    pub fn is_valid(&self) -> bool {
        use winapi::um::handleapi::INVALID_HANDLE_VALUE;
        !self.handle.is_null() && self.handle != INVALID_HANDLE_VALUE
    }
    
    pub fn as_raw(&self) -> *mut winapi::ctypes::c_void {
        self.handle
    }
}

// Drop trait：自动关闭句柄
impl Drop for ProcessHandle {
    fn drop(&mut self) {
        if self.is_valid() {
            unsafe {
                CloseHandle(self.handle);
                info!("Process handle closed successfully");
            }
        }
    }
}

impl ProcessMonitor {
    fn get_process_info(&self, pid: u32) -> Result<ProcessInfo, ProcessError> {
        use winapi::um::winbase::QueryFullProcessImageNameW;
        use winapi::um::winnt::PROCESS_QUERY_LIMITED_INFORMATION;
        use winapi::shared::minwindef::FALSE;
        
        // 安全改进：使用最小权限
        let handle = unsafe { OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, FALSE, pid) };
        
        let process_handle = unsafe { ProcessHandle::new(handle) };
        
        if !process_handle.is_valid() {
            return Err(ProcessError::OpenFailed(pid));
        }
        
        // 获取进程路径
        let mut module_name: [u16; 260] = [0; 260];
        let mut size = 260 as u32;
        
        let path = unsafe {
            let result = QueryFullProcessImageNameW(
                process_handle.as_raw(),
                0,
                module_name.as_mut_ptr(),
                &mut size
            );
            
            if result == FALSE {
                return Err(ProcessError::InfoFailed(format!("QueryFullProcessImageNameW failed for PID {}", pid)));
            }
            
            OsString::from_wide(&module_name[..size as usize])
                .to_string_lossy()
                .to_string()
        };
        
        // 提取进程名
        let name = path.rsplit('\\').next().unwrap_or("unknown").to_string();
        
        Ok(ProcessInfo {
            pid,
            name,
            path,
            parent_pid: 0,
            create_time: 0,
            is_suspicious: false,
        })
    }
}
```

**安全改进**：
- **RAII模式**：使用ProcessHandle包装器确保句柄正确关闭
- **最小权限原则**：使用PROCESS_QUERY_LIMITED_INFORMATION而非PROCESS_VM_READ
- **Drop trait**：自动调用CloseHandle，防止句柄泄漏

##### 2.3 可疑进程检测

```rust
impl ProcessMonitor {
    fn check_suspicious_processes(&mut self) -> Result<(), Box<dyn std::error::Error>> {
        // 已知恶意进程名称列表
        let suspicious_names = [
            "mimikatz.exe",
            "procdump.exe",
            "lazagne.exe",
            "bloodhound.exe",
            "sharphound.exe",
        ];
        
        // 已知可疑路径
        let suspicious_paths = [
            "\\temp\\",
            "\\tmp\\",
            "\\appdata\\local\\temp\\",
        ];
        
        for (pid, info) in self.process_cache.iter_mut() {
            let mut is_suspicious = false;
            
            // 检查进程名
            let name_lower = info.name.to_lowercase();
            for suspicious_name in &suspicious_names {
                if name_lower.contains(suspicious_name) {
                    is_suspicious = true;
                    break;
                }
            }
            
            // 检查路径
            let path_lower = info.path.to_lowercase();
            for suspicious_path in &suspicious_paths {
                if path_lower.contains(suspicious_path) {
                    is_suspicious = true;
                    break;
                }
            }
            
            info.is_suspicious = is_suspicious;
        }
        
        Ok(())
    }
}
```
